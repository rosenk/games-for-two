# Архитектурни решения

При работа по кода проверявай дали промяната взема или заменя трайно архитектурно решение. Ако да, зареди проектното умение `.agents/skills/recording-architecture-decisions/SKILL.md` и добави или актуализира ADR в `docs/adr/` заедно с промяната. При работа по съществуващ ADR също използвай умението. Не създавай ADR за рутинни поправки, които не променят архитектурата.
