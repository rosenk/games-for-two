# 0004 — Svelte 5, Vite и отделни модули

Дата: 2026-09-23
Статус: Заменено от [0013](0013-two-games-typescript.md)

## Контекст

След добавянето на P2P, глас и възстановяване статичният `app.js` смесва правила на играта, протокол, lifecycle и DOM. Необходима е по-ясна граница за развитие и тестове. Това заменя [първоначалния статичен подход](0002-static-client.md).

## Решение

Svelte 5 и Vite обслужват интерфейса, с обикновен JavaScript и заключени npm зависимости. `src/game/game-state.js` държи чистата игрова логика и сериализацията; `src/online/` държи транспорт, адреси и съхранение; `src/App.svelte` оркестрира browser lifecycle и състоянието; `src/components/` визуализира играта. PeerJS е npm зависимост в build-а, не глобален CDN скрипт. Node тестове, `svelte-check` и Vite build са част от проверката.

## Алтернативи

Запазване на монолитния DOM код би избегнало миграцията, но усложнява онлайн промени и тестове. SvelteKit не носи полза без SSR или приложен backend; React е преценен като повече boilerplate. TypeScript е обсъден, но не е приет. Отделен общ `effect.ts` слой не е въведен без повторяема отговорност.

## Последствия

Границите и тестовете са по-ясни, но разработката вече изисква Node/Vite и build за статичен hosting. `.agents/setup` инсталира заключените зависимости в orb, а `.amp/services.yaml` стартира dev preview. Production артефактът е `dist/`; [публикуването](0006-github-pages-build.md) описва това ограничение. Дев сървърът по-късно получава [bundled dev режим](0012-bundled-dev.md).
